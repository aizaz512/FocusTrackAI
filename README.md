# 🎯 FocusTrack AI

Real-Time AI-powered Focus and Productivity Monitor built using Computer Vision and Machine Learning.

## Features

- Face Detection
- Face Mesh
- Eye Tracking
- Blink Detection
- Sleep Detection
- Head Pose Estimation
- Phone Detection
- Focus Score
- SQLite Database
- Streamlit Dashboard
- Analytics

## Technologies

- Python
- OpenCV
- MediaPipe
- YOLOv8
- Streamlit
- SQLite
- Plotly

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/FocusTrackAI.git
cd FocusTrackAI

python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python main.py
```

Dashboard:

```bash
streamlit run dashboard/dashboard.py
```
